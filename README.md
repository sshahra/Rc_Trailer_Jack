# RC Trailer Jack Showcase

Recruiter-first one-page portfolio site for the RC Trailer Jack senior design project.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000`.

## Build Checks

```bash
npm run lint
npm run build
```

## Content Notes

- Curated web assets live in `public/rc-trailer-jack/`.
- Original source files remain in `Content/`.
- `Content/Slide1.JPG` is copied as `public/rc-trailer-jack/project-poster.jpg` and featured on the page.
- The large local `Video Project draft (1).mp4` is intentionally not copied into `public`.
- The full project video is embedded from YouTube and has an external fallback link in the page.
